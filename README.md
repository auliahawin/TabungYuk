# CLICK BURGER - Kivy

Project tugas tahap 1: Navigation & Event Handling.

## Fitur
- Login
- Home/menu burger
- Tambah produk ke keranjang
- Detail produk
- Keranjang dan checkout
- Pesanan saya
- Profil dan logout
- Navigasi antar halaman menggunakan ScreenManager
- Event handling tombol menggunakan `bind(on_release=...)`

## Menjalankan di VS Code (Windows)
1. Buka folder project ini di VS Code.
2. Pastikan Python dan Kivy sudah terpasang.
3. Buka Terminal VS Code.
4. Jalankan:
   `python main.py`

Jika perintah `python` tidak bekerja, coba:
`py main.py`

## Git
Buat repository GitHub baru khusus project ini, lalu:
`git init`
`git add .`
`git commit -m "Membuat navigasi dan event handling aplikasi Click Burger"`
`git branch -M main`
`git remote add origin URL_REPOSITORY_KAMU`
`git push -u origin main`
