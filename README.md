# TUTORIAL PENGGUNAAN APLIKASI TABUNGYUK #

## 1. Halaman Login
Saat aplikasi TabungYuk dibuka, pengguna akan masuk ke halaman Login.

Langkah pengguna:
1. Masukkan Username.
2. Masukkan Password.
3. Tekan tombol LOGIN.
   * Jika username dan password benar, pengguna akan masuk ke halaman Beranda.
   * Jika belum memiliki akun, tekan “Belum punya account? Daftar” untuk membuat akun baru.

## 2. Membuat Akun Baru
Pada halaman Login, tekan:
> Belum punya account? Daftar

Kemudian akan muncul halaman Buat Account.

Isi data berikut:
* Username
* Password
* Konfirmasi Password

Setelah semua terisi, tekan tombol DAFTAR.

* Jika berhasil, akan muncul pemberitahuan: Account berhasil dibuat.
* Setelah itu pengguna akan kembali ke halaman Login dan dapat masuk menggunakan akun yang telah dibuat.

## 3. Halaman Beranda
Setelah berhasil login, pengguna masuk ke halaman Beranda TabungYuk.

Pada halaman ini terdapat:
* Nama aplikasi TABUNGYUK
* Sapaan pengguna
* Tombol Berlangsung
* Tombol Tercapai
* Daftar celengan
* Tombol + TAMBAH CELENGAN
* Navigasi Beranda
* Navigasi Account

Halaman ini digunakan untuk melihat dan mengelola target tabungan pengguna.

## 4. Membuat Celengan Baru
Untuk membuat target tabungan baru, tekan:
> + TAMBAH CELENGAN

Kemudian akan muncul halaman Tambah Celengan.

Langkah pengisian:
1. Nama celengan (Contoh: Beli HP)
2. Target tabungan (Contoh: 2000000)
3. Tekan Pilih Foto untuk memilih gambar yang berhubungan dengan target tabungan.
4. Setelah selesai, tekan SIMPAN CELENGAN.

Celengan yang dibuat akan otomatis muncul di halaman Beranda.

## 5. Melihat Celengan
Pada halaman Beranda, setiap celengan memiliki informasi seperti:
* Nama celengan
* Foto target
* Jumlah tabungan saat ini
* Target tabungan
* Persentase pencapaian
* Sisa target
* Tombol Lihat Celengan

Contoh tampilan informasi:
* `Rp1` dari `Target: Rp2`
* `50% tercapai`
* `Sisa: Rp1` (Artinya jumlah tabungan saat ini adalah Rp1 dari target Rp2, sehingga sudah mencapai 50%).

## 6. Menambahkan Tabungan
Untuk menambahkan uang ke celengan:
1. Tekan Lihat Celengan.
2. Masukkan jumlah uang pada bagian Nominal menabung.
3. Masukkan keterangan pada bagian Keterangan.
4. Tekan + TAMBAH TABUNGAN.

Contoh:
* Nominal menabung : `50000`
* Keterangan : `Menabung hari ini`

Setelah tombol ditekan, jumlah tabungan akan bertambah secara otomatis dan riwayat setoran akan muncul pada bagian Riwayat Tabungan.

## 7. Melihat Riwayat Tabungan
Pada halaman detail celengan terdapat bagian Riwayat Tabungan.

Bagian ini digunakan untuk melihat catatan tabungan yang sudah dimasukkan. Informasi yang ditampilkan meliputi:
* Tanggal
* Keterangan
* Jumlah tabungan

Dengan begitu, pengguna dapat memantau riwayat uang yang sudah ditabung secara berkala.

## 8. Target Tabungan Tercapai
Jika jumlah tabungan sudah sama dengan atau lebih besar dari target, aplikasi akan menampilkan:
* `100% tercapai`
* `Target sudah tercapai`

Celengan tersebut dapat dilihat melalui tab Tercapai, sedangkan celengan yang belum mencapai target berada pada tab Berlangsung.

## 9. Menghapus Celengan
Jika ingin menghapus celengan:
1. Buka celengan dengan menekan Lihat Celengan.
2. Tekan tombol Hapus.
3. Data celengan dan data tabungan yang berkaitan dengan celengan tersebut akan dihapus.

## 10. Halaman Account
Untuk membuka halaman Account, tekan menu Account.

Pada halaman ini pengguna dapat melihat:
* Foto profil
* Username
* Tombol Ganti Foto Profil
* Tombol LOGOUT

## 11. Mengganti Foto Profil
Pada halaman Account:
1. Tekan Ganti Foto Profil.
2. Pilih foto dari komputer atau galeri.
3. Foto yang dipilih akan digunakan sebagai foto profil dan tersimpan pada akun pengguna.

## 12. Logout
Jika ingin keluar dari akun:
1. Masuk ke halaman **Account**.
2. Tekan **LOGOUT**.
3. Pengguna akan kembali ke halaman Login.
